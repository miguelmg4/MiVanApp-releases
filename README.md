# MiVanApp — Releases

Este repositorio contiene únicamente los `.apk` de cada versión publicada de
[MiVanApp](https://github.com/miguelmg4/MiVanApp), para que la propia app pueda
comprobar actualizaciones y descargarlas sin depender de Google Play.

El código fuente de la app **no** vive aquí (es privado); este repo solo aloja
los binarios de las releases.
